# CLAUDE.md

SnapDraw is a local-only Chrome MV3 extension: capture the visible viewport, annotate with Excalidraw,
record tab/whole-screen video. **Read [AGENTS.md](AGENTS.md) first** (rules, commands, quirks, done
criteria) and [ARCHITECTURE.md](ARCHITECTURE.md) for components, flows and contracts.

## Critical invariants

- **Local-only:** no backend, analytics, telemetry, CDN or remote fonts. The extension pages have a
  strict `'self'`-only CSP; don't add network code or remote assets. Only SnapDraw's own repo/issues
  links are allowed (`src/editor/links.ts`).
- **Exact permissions:** `activeTab`, `clipboardWrite`, `offscreen`, `tabCapture`; no
  `host_permissions`, no `content_scripts` (`scripts/validate-build.mjs`, `tests/manifest.test.ts`).
- **Never change `public/manifest.json` `key`** (extension ID): history, shortcut and clipboard grants
  depend on it.
- **Keep the Excalidraw 0.18.1 workarounds:** `src/utils/image-conversion.ts` SVG wrapper +
  disabled dark canvas filter (colour fidelity), `src/editor/excalidrawActions.ts` synthetic undo/redo,
  `src/utils/canvas-readback.ts` shim, `public/excalidraw-asset-path.js` classic font path. Don't
  upgrade Excalidraw casually.
- **Media stays local:** screenshots/recordings live in IndexedDB (`snapdraw` → `screenshots`), bounded
  by `HISTORY_LIMIT = 20` / 30 days. Don't delete records on editor load.
- **Generated files:** `dist/`, `public/fonts/`, `test-results/`, `.sandbox/`, `.tmp-*/` are gitignored;
  `docs/screenshots/*.png` are regenerated by E2E. Don't hand-edit generated output.

## Verify before committing

```powershell
node node_modules/typescript/bin/tsc --noEmit
node node_modules/vitest/vitest.mjs run
node node_modules/vite/bin/vite.js build
node scripts/validate-build.mjs
# E2E (needs dist/ + Chrome 137+, unsandboxed Chrome):
node scripts/e2e.mjs
```

`npm.ps1` may be blocked by execution policy — use `cmd /c npm …` or the direct Node commands above.
If Vite fails with `spawn EPERM`/`net use`, set
`NODE_OPTIONS="--require <repo>\.sandbox\no-spawn.cjs"` before building. Chrome cannot start under the
default agent sandbox; Chrome-based verification needs danger-full-access. Never rewrite UTF-8 files
through PowerShell `Get-Content`/`Set-Content`; use the edit/write tools.

## Workflow

Create `feature/<change>` or `fix/<change>`, commit (author `GaurangPohankar
<pohankargaurang@gmail.com>`), merge `--no-ff` into `main`, push to
`https://github.com/GaurangPohankar/SnapDraw.git`. After each build, reload the extension in
`chrome://extensions`.
